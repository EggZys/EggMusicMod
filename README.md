# 🥚 EggMusicMod

Мод для десктопного приложения Яндекс Музыка, убирающий подписку Плюс и ограничения.

Основан на [YandexMusicBetaMod](https://github.com/Stephanzion/YandexMusicBetaMod).

## Возможности

- Работает без Плюса
- Высокое качество аудио
- Скачивание треков в FLAC/MP3
- Интеграция с Discord
- Кастомные темы и шрифты
- Отключена реклама и аналитика
- Отключены авто-обновления

## Установка

1. Скачай последний релиз: https://github.com/EggZys/EggMusicMod/releases/latest
2. Установи и пользуйся

## Сборка из исходников

```
bun install
bun start
```
